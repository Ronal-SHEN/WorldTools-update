
WorldTools is a Minecraft mod that lets you download a detailed copy of a server's world — including chunks, entities, block entities, and player data — and save it as a fully playable singleplayer world.

This project is a fork of the original [WorldTools](https://github.com/Avanatiker/WorldTools), updated to support newer Minecraft versions(1.21.5+) on Fabric and NeoForge, with some bugs fixed.

For features and usage instructions, please refer to the original project.
